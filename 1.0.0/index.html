This specification profiles [[WARC]]. It states which records BrowserHive writes into a WARC file and what each of them holds, so that a reader holding only the file can tell what the capture recorded and what it left out.

This version is being written. Its sections are added before it is referenced by anything.

Conformance

Where this specification uses the terms MUST, MUST NOT, SHOULD and MAY, they are to be interpreted as described in [[RFC2119]].
